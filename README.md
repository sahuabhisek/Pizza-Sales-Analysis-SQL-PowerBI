# 🍕 Pizza Sales Analysis | SQL & Power BI

## 📌 Project Overview

This project focuses on analyzing pizza sales data using PostgreSQL and Microsoft Power BI.

The objective is to identify sales trends, evaluate pizza product performance, analyze category-wise sales, and develop an interactive dashboard that helps businesses make data-driven decisions.

This end-to-end project demonstrates practical SQL querying, business KPI analysis, data visualization, and business intelligence skills.

## 🎯 Business Objectives

- Analyze overall pizza sales performance.
- Calculate important business KPIs.
- Identify the highest and lowest revenue-generating pizzas.
- Analyze pizza category and size performance.
- Understand monthly sales trends.
- Compare pizza quantities and order patterns.
- Build an interactive Power BI dashboard.
